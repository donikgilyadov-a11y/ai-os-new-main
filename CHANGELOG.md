# Changelog

## Unreleased

- **Тесты**: e2e-смоук теперь поднимает локальный мок Telegram Bot API и проверяет реальную публикацию ветки
  через адаптер и publisher (два сообщения, текст, ссылка на пост), а не только состояние UI.

## 0.2.1

- **История**: кнопка `CSV` экспортирует текущую фильтрованную выборку. Разделитель `;`, BOM для корректного
  отображения кириллицы в Excel, одна строка на аккаунт со статусом, датой, текстом, ссылкой и ошибкой.
- **Обновления**: `electron-updater` + секция «Обновления» в настройках. Тихая проверка при старте (через 30 с),
  кнопки «проверить/скачать/перезапустить и установить», прогресс загрузки. В dev-режиме проверка отключена.

## 0.2.0

- **Instagram**: bundled-плагин Graph API — текстовые посты, фото и карусели (медиа по публичному `imageBaseUrl`),
 ожидание готовности контейнера и получение shortcode для ссылки; метрики для «Пульса».
- **Плагины**: исправлена загрузка manifest.json с BOM (из-за этого пример `webhook` не подключался); смоук теперь
  проверяет наличие обоих плагинов.
- **LinkedIn**: новый адаптер (личный профиль и страницы компаний, изображения с alt-текстом).
- **Alt-текст**: редактор описаний медиа прямо в композере (кнопка `alt` на посте).
- **Черновики**: панель черновиков — явное сохранение, загрузка и удаление; автосохранение продолжает работать.
- **История**: новая вкладка с архивом публикаций — поиск по тексту/аккаунтам, фильтры по статусу и площадке,
  просмотр результата по каждому аккаунту, повторная загрузка поста в композер и удаление записи.
- **Пресеты**: экспорт/импорт алиасов, групп, профилей (без токенов) и настроек в JSON. При указании пароля бэкапа
  файл шифруется через scrypt + AES-256-GCM (`GPENC1:`), пароль никуда не сохраняется.
- **Планировщик**: исправлено нативное расписание Mastodon/Facebook — площадки теперь получают будущую дату сразу при
  создании записи, а не в момент наступления времени; остальные аккаунты остаются в локальной очереди.
- **CI**: релизный workflow — сборка установщика и публикация GitHub Release по тегу `v*`.
- Мелочи: короткие коды платформ (TG/FB/BS/IN), высота редактора, позиция тостов.

## 0.1.0
