# Gridpost

Легковесный open-source десктопный клиент для ведения мультиязычной сетки соцсетей из одного компактного окна.

**Local-first · Zero-backend · API + WebView · Плагины**

Окно 460×720, тёмная тема, глобальная горячая клавиша, работа из трея. Все токены, cookies, черновики и медиа
хранятся только на устройстве и шифруются системным хранилищем секретов (Windows DPAPI через Electron `safeStorage`).

## Установка и запуск

```bash
npm install
npm run dev          # разработка (Vite + Electron)
npm run typecheck    # проверка типов main/preload и renderer
npm run build        # сборка в out/
npm run smoke        # e2e-смоук: сборка + сценарий в Electron (playwright-core)
npm run dist         # NSIS-установщик для Windows
```

Требуется Node.js 20+. Для запуска с отдельным профилем (портативный режим, тесты):
`GRIDPOST_DATA_DIR=C:\path\to\profile npm run start`.

Смоук-тест создаёт временный профиль, проходит мастер аккаунта, ветку постов, превью, панель черновиков, историю
с повторной загрузкой поста в композер, проверяет шифрование и сохранность данных после перезапуска; скриншоты
складываются в `%TEMP%/gridpost-shots`.

> Сборка установщика на Windows требует распаковки `winCodeSign` (архив с симлинками), поэтому в `package.json`
> выставлено `win.signAndEditExecutable: false` — сборка работает и без прав на симлинки (установщик остаётся
> без код-подписи и без встроенного Manifest-ресурса). Подпись можно включить, вернув это поле в `true`
> на машине с правами на симлинки и с сертификатом.

## Быстрый старт

1. `Настройки → Аккаунты → Добавить аккаунт`.
2. Выберите платформу и метод: **API-ключ** (поля подскажут, где взять токен) или **WebView** (вход в изолированном окне).
3. Задайте имя, язык (`EN`, `RU`, …) и цвет — язык используется для языковых вкладок.
4. Вернитесь на вкладку «Пост», выберите аккаунты чипами сверху и напишите текст.
5. `Перевести` — разложит текст по остальным языкам выбранных аккаунтов.
6. `Публиковать` или `Позже` (расписание).

Горячая клавиша по умолчанию — `Alt+Shift+P` (окно поверх всех, повторное нажатие скрывает).

## Архитектура

```
src/
  shared/        типы домена и константы (используются main и renderer)
  main/          Electron main process
    index.ts     окно, трей, хоткей, прокси-аутентификация, bootstrap
    ipc.ts       IPC-контракт с renderer
    store.ts     зашифрованное хранилище (safeStorage) + медиа
    publisher.ts очередь, jitter, ретраи, планировщик
    media.ts     preflight-сжатие/ресайз под лимиты площадок
    ai.ts        Ollama / OpenAI-совместимый переводчик
    adapters/    контракт + telegram, x, bluesky, mastodon, facebook, linkedin, plugins
    session-login.ts  изолированный WebView-вход и захват cookies
  preload/       contextBridge API (window.gridpost)
  renderer/      React + zustand UI
plugins/         примеры плагинов (webhook)
```

Поток публикации:

1. Renderer собирает `variants: { lang: ThreadPost[] }` из вкладок и отправляет `post:create`.
2. Main создаёт `PostRecord` с результатом на каждый аккаунт и, если время не задано, публикует сразу.
3. `Publisher` резолвит язык аккаунта → вариант текста → алиасы → preflight медиа → `adapter.publish()`.
4. Между аккаунтами одной площадки выдерживается jitter; статус каждого аккаунта обновляется отдельно.
5. Ошибки не блокируют остальных: доступен «ретрай только неуспешных».

Хранилище: `%APPDATA%/gridpost/gridpost.store` (payload зашифрован `safeStorage`), медиа — `%APPDATA%/gridpost/media`.

## Безопасность и приватность

- Нет собственного бэкенда: приложение не отправляет данные разработчику.
- Токены и cookies не попадают в renderer в открытом виде при работе с WebView; файл хранилища шифруется ОС.
- Каждый аккаунт — отдельная сессия Electron (cookies, localStorage, кэш) и, при необходимости, отдельный прокси.
- Плагины исполняются в main-процессе с полными правами: ставьте только доверенные плагины.
- `plain` в заголовке означает, что ОС не предоставила шифрование — файл сохранён в base64 без шифрования.
- Экспорт пресетов по умолчанию — открытый JSON (без токенов). С непустым полем «Пароль бэкапа» файл шифруется
  scrypt + AES-256-GCM; пароль не сохраняется и нужен только при импорте.

## Ограничения MVP

- Нативное расписание площадок, которые его не поддерживают (X, Telegram, Bluesky), выполняет локальный планировщик:
  если ПК выключен, при следующем запуске появится диалог «опубликовать сейчас / перенести / в черновики».
- Threads, Reddit, TenChat не входят в ядро — добавляются плагинами. Instagram поставляется как bundled-плагин
  (`plugins/instagram`); локальные фото требуют публичной папки-зеркала, поскольку Graph API принимает только URL.
- Прокси применяется к сессии аккаунта (API-запросы и WebView), а не к самому окну приложения.
